# Findings from the first five drafts

Field reports from the agents that wrote the drafts in `examples/`, the shared brief they worked from, and the
`scene.yaml` each one wished it could have written. Input for the player and a future scene format, not
something the skill reads at run time.

- `BRIEF.md`: the shared brief.
- `<draft>/NOTES.md`: what fit, what was missing, what an AI author gets wrong.
- `<draft>/scene.yaml`: the scene format as if a compiler existed (not a spec).
- `hash-table/hash_trace.py`, `verify.py`: states checked against a real hash table (`pip install pyyaml`, then `python3 verify.py`).

Note: `examples/hash-table/index.html` says it was generated by a `build.py` that was not kept. Treat that page as a finished example, not a source.
