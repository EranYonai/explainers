You type one sentence. What comes back?

You ask Claude to explain something. A few minutes later you get one web page that anyone can open on a phone. Below, that page builds itself one piece at a time. Press Next.

An explainer is a question, a picture that changes with every step, one choice for the reader, and a one-line answer.

When to make one

It is worth it when a picture beats a paragraph: how a system behaves, why a bug happened, what a change does. It is not worth it for a fact that fits in one sentence.

To try it, install the skill and ask for "an explainer of" whatever you want to teach.
