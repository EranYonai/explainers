Why did LLM apps move from chains to graphs?

Early LLM apps were built as a straight line of steps. Today's agents are built as maps with loops in them. Something forced that change. Ride the line to see what.

A chain can only go forward. Agents loop, branch and wait, so the route became a graph.

Which one to use

A straight chain is still right for a fixed job like "summarise this". LangGraph is for when the model, a tool result or a person decides the next stop [1]. Saving the state at every stop is what lets a run pause for a person and resume later [2] [3]. LangChain's create_agent builds the standard loop above on top of LangGraph for you [4].
