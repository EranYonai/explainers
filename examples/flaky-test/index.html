Why did the same test pass, then fail, with no code change?

Green yesterday, red this morning, green again when you rerun it. Nothing changed in the code, so something else is deciding the result.

The code never changed. The timing did, and the test was measuring the timing.

The fix is to wait for the thing itself: join the thread, await the result, or poll until the condition is true. Retries make the dashboard green but leave the race in place, and users can't rerun production.
